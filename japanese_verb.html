日語動詞變化規則總覽與即時拆解

掌握 I 類（五段）、II 類（一段）與 III 類不規則動詞的核心分類原則，以及音便口訣與句型接續。

GROUP I · 五段活用

I 類動詞（非る結尾，或非い/え段＋る）

字尾位於「う段」（う、く、ぐ、す、つ、ぬ、ぶ、む、る）。變化時依五十音行移動段位，て/た形須注意「音便」。

變化形轉換規則範例（書く・話す）
ます形う段 → い段 ＋ ますかきます・はなします
ない形う段 → あ段 ＋ ない（う→わ）かかない・あわない
て / た形依詞尾發生促音/撥音/い音便かいて・はなして
ば / 可能形う段 → え段 ＋ ば / るかけば・かける
意向形う段 → お段 ＋ うかこう・はなそう
GROUP II · 上・下一段

II 類動詞（い段 / え段假名 ＋ る）

字尾必為「る」，且倒數第二音為「い段」或「え段」（少數例外如 帰る、切る、入る、知る、走る 屬 I 類）。去「る」直接接續，最規律！

變化形轉換規則範例（食べる・起きる）
ます形去 る ＋ ますたべます・おきます
ない形去 る ＋ ないたべない・おきない
て / た形去 る ＋ て / たたべて・おきた
ば形去 る ＋ ればたべれば・おきれば
可能 / 意向去 る ＋ られる / ようたべられる・たべよう
GROUP III · 不規則

III 類動詞（する・来る）

僅「する（以及 名詞＋する 複合動詞）」與「来る（くる）」兩組核心不規則動詞，必須整體記憶詞幹讀音變化。

變化形する（勉強する）来る（くる）
ます形します（べんきょうします）きます（きます）
ない形しないこない（注意讀音 こ）
て / た形して / したきて / きた
ば形すればくれば
可能 / 意向できる / しようこられる / こよう
I 類動詞 音便口訣

て形・た形 音便快速記憶表

詞尾音便變化來源動詞實例
う・つ・る→ って / った（促音便）買う→かって、待つ→まって、帰る→かえって
む・ぶ・ぬ→ んで / んだ（撥音便）飲む→のんで、遊ぶ→あそんで、死ぬ→しんで
く→ いて / いた（い音便）書く→かいて、聞く→きいて（例外：行く→いって）
ぐ→ いで / いだ（濁音便）泳ぐ→およいで、急ぐ→いそいで、脱ぐ→ぬいで
す→ して / した（無音便）話す→はなして、出す→だして、消す→けして
